# Remote Job Search Research

Research and job trackers for remote opportunities
accessible from Tunisia.

## Categories

- Customer Support
- Technical Support
- Embedded Systems
- Embedded Linux
- Firmware Development
- IoT Engineering

## Contents

The reports/ folder contains PDF research reports
and Excel trackers with hiring requirements,
salary information, application links, and
job compatibility assessments.

Note: Job availability and salary information
may change after the report date.
